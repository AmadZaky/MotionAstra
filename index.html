Quick Tools

Tools operate on selected layers. Every action has one Undo step.

Anchor point

Supports text, shapes, footage, solids, nulls, parenting and 3D. Cameras/lights have no anchor.

Offsets existing keys and expressions. Animated scale/rotation can change other frames after changing the pivot.

Align & distribute

Align visual bounds to the composition. Distribute centers evenly between the outermost selected layers (3+). Supports 2D layers and 2D parents.

Position & parenting

Position offsets use parent coordinates and preserve existing keys/expressions.

Parenting preserves the current frame. Review motion if an old parent was animated.

Keyframe easing

Changes the underlying text style, including counters and switchers.

Remove effects

Removes effects only from selected unlocked layers.
